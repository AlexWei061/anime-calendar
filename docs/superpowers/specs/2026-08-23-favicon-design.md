# 「番时表」Favicon 设计说明

## 目标

为「番时表｜新番日历」设计一个简洁、成熟且具有辨识度的浏览器标签页图标。图标需在 16×16 像素下仍能识别“日历 + 播放”的核心含义，并同时适配亮色与暗色浏览器界面。

## 定稿方向

采用 A3「翻页播放」：以玫红色圆角日历页为主体，在中央使用白色播放三角，右下角加入青色翻页。日历表达排期，播放符号表达番剧，翻页让轮廓区别于通用日历图标。

## 视觉规格

- 画布：`64×64` SVG，透明背景，图形外沿保留安全留白。
- 主轮廓：圆角日历页，顶部和左侧保持完整圆角，右下角由翻页形成斜切轮廓。
- 主色：使用站点玫红色系，允许从 `#cf4b7b` 到 `#96306d` 的轻微渐变。
- 主符号：居中的白色播放三角；轮廓简洁，不添加阴影或细描边。
- 辅助色：右下角青色翻页使用 `#64d2cf`，定稿时比概念稿略放大，保证 16px 下可见。
- 日历提示：顶部保留一条简洁浅色横线，不使用细小挂环、文字或日期数字。
- 主题：只提供一个主题无关版本；其对比度应同时适合浅色和深色标签栏。

## 实现边界

- 仅替换 `public/favicon.svg`，不修改页面布局、元数据标题、主题 token 或运行时逻辑。
- 保持 SVG 为代码原生矢量，不引入位图、第三方资源或新依赖。
- 不覆盖或整理当前工作区中与 favicon 无关的改动。

## 验收

- SVG 可被浏览器直接解析，`viewBox` 为 `0 0 64 64`。
- 在 64px、32px 和 16px 下检查：主体轮廓、播放三角均清晰；16px 下青色翻页仍可辨认。
- 在浅色和深色背景上检查边缘与主符号对比。
- 运行现有 lint 与测试，确认静态资源替换未影响构建和页面行为。
