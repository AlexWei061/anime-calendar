# 并排时间轴节目卡封面与标题优先设计

## 目标

当桌面“播出表”或“我的番剧”的周时间轴在同一时段出现两张及以上节目卡时，优先显示番剧封面和作品名，而不是集数。用户应能先用封面与文字辨认作品；过长中文标题被截断时，悬停仍能看到完整名称。

成功标准：并排紧凑卡片显示固定比例的彩色封面和单行中文标题，隐藏“第 N 集”；标题的原生悬停提示显示完整中文番名；卡片仍能打开详情，逐集已看仍可独立操作；单列时间轴卡片与移动端单日议程完全不变。

## 版式与行为

- 仅影响同时段多列布局产生的 `.timeline-event-compact` 桌面卡片。
- 紧凑卡片恢复与普通桌面时间轴卡片相同的左侧封面列：封面保持 3:4 比例，以约 `1.85rem × 40px` 显示，不拉伸、不裁切为背景图。
- 紧凑卡片保留单行、超长省略的中文作品标题；封面和作品名共同作为首要识别信息。
- 紧凑卡片隐藏“第 N 集”，避免在 40px 高度的并排卡中挤占作品名空间。
- 标题继续使用现有 `title={event.titleZh}` 属性，因此鼠标停留在截断标题上时，浏览器原生提示完整中文番名；不新增自定义 tooltip 组件。
- 每张卡片右上角保留现有 `0.75rem` 已看方框，其 `aria-pressed`、逐集 `aria-label`、保存中状态与点击行为均不变。
- 整张卡片仍是打开原生详情弹窗的按钮，保留现有完整作品名、集数、日期和时刻组成的无障碍标签；隐藏可见集数不得降低读屏信息。

## 实现边界

- `app/page.tsx` 的事件布局判定、封面 `CoverArt` 标记、带 `title` 属性的标题、详情按钮和已看控件均已具备，不修改 JSX、状态、路由、日历计算或 API。
- 仅在 `app/globals.css` 将紧凑卡片的“隐藏标题”规则替换为“隐藏集数”规则；封面继续继承普通时间轴卡片的网格与显示规则。
- 不新增颜色、图片资源、设计 token 或断点；继续使用现有封面图集与双主题 token。
- 不影响单列 `.timeline-event`、查询结果、追番统计卡片、详情弹窗，或小于等于 `860px` 的移动端议程。

## 验证

- 先更新 `tests/rendered-html.test.mjs` 的源码契约：紧凑卡片必须有封面列且封面可见，标题保持显示并带完整中文名的 `title` 属性，集数隐藏，而同一时段卡片的无障碍语义保持。
- 运行定向渲染测试、`npm run lint -- --ignore-pattern .worktrees`、`npm test` 和 `git diff --check`。
- 在桌面浅色与深色主题下人工确认两张并排节目卡能优先辨认封面与标题，鼠标停留可显示完整中文番名，已看方框可用；在 390px 宽度确认移动端议程无变化。
