# 并排时间轴节目卡封面优先设计

## 目标

当桌面“播出表”或“我的番剧”的周时间轴在同一时段出现两张及以上节目卡时，优先显示番剧封面，而不是被截断的作品名。用户应能用封面快速辨认作品，同时继续看到集数和独立的已看方框。

成功标准：并排紧凑卡片显示固定比例的彩色封面，标题不再争夺宽度；卡片仍能打开详情，逐集已看仍可独立操作；单列时间轴卡片与移动端单日议程完全不变。

## 版式与行为

- 仅影响同时段多列布局产生的 `.timeline-event-compact` 桌面卡片。
- 紧凑卡片恢复与普通桌面时间轴卡片相同的左侧封面列：封面保持 3:4 比例，以约 `1.85rem × 40px` 显示，不拉伸、不裁切为背景图。
- 紧凑卡片隐藏作品标题；封面作为首要识别信息，右侧只保留“第 N 集”文字。
- 每张卡片右上角保留现有 `0.75rem` 已看方框，其 `aria-pressed`、逐集 `aria-label`、保存中状态与点击行为均不变。
- 整张卡片仍是打开原生详情弹窗的按钮，保留现有完整作品名、集数、日期和时刻组成的无障碍标签；隐藏可见标题不得降低读屏信息。

## 实现边界

- `app/page.tsx` 的事件布局判定、封面 `CoverArt` 标记、详情按钮和已看控件均已具备，不修改 JSX、状态、路由、日历计算或 API。
- 仅在 `app/globals.css` 覆盖紧凑卡片的两条现有规则：恢复双列网格与封面显示，并为紧凑卡片的标题设为不显示。
- 不新增颜色、图片资源、设计 token 或断点；继续使用现有封面图集与双主题 token。
- 不影响单列 `.timeline-event`、查询结果、追番统计卡片、详情弹窗，或小于等于 `860px` 的移动端议程。

## 验证

- 先更新 `tests/rendered-html.test.mjs` 的源码契约：紧凑卡片必须有封面列且封面可见，标题隐藏，而集数的省略与同一时段卡片的无障碍语义保持。
- 运行定向渲染测试、`npm run lint -- --ignore-pattern .worktrees`、`npm test` 和 `git diff --check`。
- 在桌面浅色与深色主题下人工确认两张并排节目卡能优先辨认封面，集数与已看方框可用；在 390px 宽度确认移动端议程无变化。
