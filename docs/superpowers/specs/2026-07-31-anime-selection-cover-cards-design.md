# 选择番剧封面卡设计

## 目标

在“我的番剧”的“选择番剧”折叠面板中，以与“追番统计”一致的卡片语言展示每部作品：完整的 3:4 封面、中文标题和日文标题。用户仍通过原有复选框选择作品，选择结果继续自动保存并同步。

## 范围

- 仅修改选择面板的单项标记与样式。
- 复用现有 `CoverArt` 及其本地封面图集。
- 保留现有 `toggleAnimeSelection`、禁用状态、认证、保存 API、折叠面板和已选中视觉语义。
- 桌面仍以响应式多列网格显示；`860px` 及以下仍为单列。

## 结构与交互

每个作品继续使用关联复选框的 `label`，内部按以下顺序排列：

1. 原有复选框；
2. `CoverArt` 渲染的 3:4 完整封面；
3. 包含中文标题和日文标题的文本区域。

复选框继续是唯一的选择控件。卡片点击、键盘操作、保存过程中的禁用状态，以及粉色选中边框和背景均维持现有行为。

## 样式

- 选择列表使用与统计卡列表相近的最小列宽，避免 203 部作品在宽屏被拉成过宽卡片。
- 封面沿用统计卡的比例、圆角和裁切方式；文本区域允许长标题省略，避免撑破网格。
- 仅使用已有 CSS 设计 token；暗色与浅色主题自动继承现有 token。
- 移动端将列表保持为单列，卡片内部排列不改变。

## 验证

在 `tests/rendered-html.test.mjs` 先添加渲染结构断言，证明封面和中日标题位于选择项中，同时复选框及选择状态来源仍在。测试先应因缺少新结构失败；随后进行最小代码和样式改动，并执行项目规定的 lint 与完整测试。
