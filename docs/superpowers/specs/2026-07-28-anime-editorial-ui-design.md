# 当季编辑页 UI 改版设计

**状态：** 已完成交互设计确认，待审阅实施计划
**日期：** 2026-07-28

## 目标

在不改变番剧排期、账号、追番和 URL 路由语义的前提下，把默认“播出表”改为更有二次元气质的“当季编辑页”：

- 桌面端首屏先传达当季内容，再自然引导到一周放送表。
- 用现有的本地封面图集、季度信息和粉彩 token 建立季番杂志感，而不是只叠加装饰。
- 释放现有左侧栏占用的横向空间，让首屏和周表能完整展示。
- 保留移动端单日选择器、单日议程，以及已有的浅色/深色主题能力。

## 非目标

- 不新增推荐算法、第三方数据、账号字段、番剧数据或数据库迁移。
- 不改变“我的番剧”“追番统计”“查询番剧”现有数据与 URL 状态模型。
- 不改变周历的排期计算、已看标记、详情弹窗或封面图集格式。
- 不重做 Kimi 已加入的主题切换；新增样式继续消费同一套 token。

## 页面结构

### 全局导航

将 `.site-shell` 从“固定左侧栏 + 主内容”改为纵向结构。桌面端导航变成页面顶部的主导航：

1. 左侧为品牌“番时表”。
2. 中部为“播出表”“我的番剧”“追番统计”；继续使用现有 `changePage()` 和 `aria-current`。
3. 右侧保留登录/注册、昵称和退出入口，继续使用现有账号状态与弹窗。

导航在桌面端吸顶，以细分隔线和半透明卡片背景与内容区区分。移动端不采用桌面主导航布局，保持当前可换行的胶囊导航和账号入口。

### 默认播出表的当季编辑首屏

只在 `activePage === "all"` 时，在周表前显示编辑首屏：

1. 左侧：当季标签、标题“这季有什么值得追？”，以及当前 `activeSeason.catalogCount`、北京时间说明。
2. 主操作：
   - “查看本周放送”平滑滚动到既有一周放送安排；
   - 季度选择继续调用 `changeSeason()`；
   - 来源链接保持现有的 `activeSeason.sourceUrl`。
3. 右侧：从 `activeSeason.anime` 取固定少量条目，复用 `CoverArt` 与本地 WebP 图集制作纯装饰性的封面拼贴；封面不构成新的推荐列表。
4. 首屏下方为三列快捷区：
   - “今天看什么”：把周历定位到北京时间今天所在周，并在移动端同步选择今天；
   - “我的追番”：使用已有 `changePage("mine")`；
   - 查询：保留当前的 `page-search` 表单与提交语义。
5. 快捷区下方立即是原有“一周放送安排”和周导航；不改动时间轴的数据和布局算法。

“我的番剧”“追番统计”“查询番剧”仍使用简洁的既有页头，而不强行塞入当季封面首屏。

### 响应式布局

`max-width: 860px` 时：

- 顶部品牌行保留，页面导航继续以现有胶囊按钮换行展示。
- 当季首屏改成单列：文本、紧凑的一行封面拼贴、搜索、快捷入口、单日议程依序出现。
- 保持既有移动端单日选择器和议程；关闭桌面周表表头/导航的吸顶行为。
- 快捷区不得横向溢出，必要时从三列压成单列或紧凑网格。

## 交互和无障碍

- 导航、账号、查询、详情、收藏和已看功能保持现有按钮/表单语义和键盘行为。
- 主操作使用真实 `<button>`；滚动目标拥有稳定的标题或区域 ID，以便屏幕阅读器理解跳转位置。
- 封面拼贴使用 `CoverArt` 的装饰模式，不重复宣读封面替代文本。
- 颜色只通过 `app/globals.css` 的设计 token 使用；浅色/深色均定义可读的文本、边框和强调色。
- 新增的悬浮或滚动效果进入现有 `prefers-reduced-motion` 规则；焦点样式沿用全局 `:focus-visible`。

## 修改边界

预计只改动以下运行时与测试表面：

- `app/page.tsx`：顶部导航、默认页编辑首屏、滚动/跳转回调，以及复用现有数据与组件。
- `app/globals.css`：桌面顶部导航、当季编辑首屏、快捷区和相应的移动端规则；不替换既有双主题 token。
- `tests/rendered-html.test.mjs`：覆盖主导航、编辑首屏、既有查询/周表继续存在、移动端关键 CSS 约束和可访问语义。

不改动数据文件、排期库、认证 API、D1 schema、构建配置或生成的图集。

## 验证

实现时先添加能验证用户可见结构和交互约束的回归断言，再做最小改动。完成后运行：

```bash
npm run lint -- --ignore-pattern .worktrees
npm test
```

再检查 `git diff --check`，并在桌面与不大于 860px 的移动断点人工核对：主导航、首屏封面拼贴、搜索、周表/单日议程、浅色和深色主题。
