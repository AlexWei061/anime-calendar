5摸底小测（答错没关系，正好暴露知识盲区）

1. 这个网站的番剧排期数据（哪部番周几几点播），运行时主要从哪里来？

排期是静态数据：用脚本定期从 AniList / YUC / しょぼいカレンダー抓取后生成 data/ 下的 JS 文件，发布时打包进网站。数据库 D1 里只存用户个人数据（账号、追番、已看）。这是本项目最重要的设计之一，详见第 05 章。

2. 这个项目的界面框架 React 的核心思想，用数学等式表达是？

React 里每个组件都是一个函数：输入 state（状态），输出界面。状态变了，函数重新执行，界面自动更新。你不需要手动改 DOM，只需要改状态——这就是“声明式”。第 03 章会把它讲透。

3. 项目里 npm test 一条命令实际做了什么？

package.json 里写得很清楚：test = typecheck && build && node --test tests/*.test.mjs。三步全过才算健康——这就是你以后每次改完代码的“交卷”动作，详见第 09 章。
