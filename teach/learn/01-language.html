语法不是墙，
只是换了记号

你不需要先“学完 JavaScript”。目标是看到本项目的代码时，能把陌生写法翻译回已经掌握的数据结构、函数和控制流。

MENTAL MODEL

先别学完整门语言

这个仓库主要使用 JavaScript、TypeScript 和 JSX。它们共享一套运行语义：TypeScript 在运行前提供类型检查，最后仍由 JavaScript 引擎执行。

把 TypeScript 想成更强的赛前静态检查器：它能证明“一类写法不可能正确”，但不能代替测试证明程序在所有输入上正确。
阅读不变量先认出数据形状与控制流，再查语法；不要因为一个关键字陌生，就暂停理解整个函数。

const

变量名不能重新指向别的值；对象内部仍然可以变化。不是 C++ 的深度常量。

let

变量之后需要重新赋值。项目中能用 const 时通常不用 let。

===

严格相等，不做隐式类型转换。维护项目时几乎总该用它。

null / undefined

null 常表示明确“没有值”；undefined 常表示字段未提供。

DATA SHAPES

对象和数组：你每天都在用

C++
struct Anime {
  string id;
  string titleZh;
  int episodeCount;
};
TypeScript
type Anime = {
  id: string;
  titleZh: string;
  episodeCount: number;
};

两边都在描述同一个“记录的形状”。区别是 TypeScript 的类型通常不会变成运行时对象；它只在检查阶段帮助你。

FUNCTIONS

函数可以像整数一样被传递

const seasonIndexByAnimeId = new Map(
  seasons.flatMap((season, seasonIndex) =>
    season.anime.map((record) => [record.id, seasonIndex]),
  ),
);
不要逐字符读。按四个问题拆：
输入
seasons 季度数组。
局部变换
每部作品变成 [id, seasonIndex]。
合并
flatMap 把多季二维结果摊平。
输出
按稳定 ID 查询季度下标的 Map。

箭头函数 (x) => y 就是短函数。函数作为参数传给 map、filter 和事件监听器，是这个项目最常见的写法之一。

MODULES & NULLABILITY

从 import 块读出依赖图

import { matchesAnimeTitle } from "../lib/anime-search.js";
import {
  eventsForWeek,
  layoutTimelineEvents,
} from "../lib/calendar.js";

这两行已经告诉你：页面不自己实现搜索和排期算法，它依赖 lib/。阅读大文件时，import 比 JSX 更适合当第一站。

record?.field

如果 record 是空值，整个表达式得到 undefined，不会继续访问字段。

value ?? fallback

只有值为 null 或 undefined 才使用后备值；0 和空字符串不会被误判。

{ ...record, date }

复制对象字段，并用后面的同名字段覆盖前面的值。

as Anime[]

告诉类型检查器“把它视为这个类型”；它不会在运行时验证数据。

ASYNC

为什么代码里有满屏的 await

算法题里读入通常立刻完成；网络和数据库像把查询交给远处评测机。await 表示“这个异步函数在这里暂停，事件循环可以继续处理别的工作”。

只有标记为 async 的函数才能直接使用 await；它总会返回一个 Promise。

const response = await fetch("/api/auth/me");
if (!response.ok) return;
const user = await response.json();
setCurrentUser(user);
  1. fetch 发请求，返回 Promise。
  2. 第一个 await 等响应头和响应对象。
  3. response.json() 仍是异步读取与解析。
  4. setCurrentUser 改 React 状态，触发下一次渲染。
异常边界await 不等于自动处理失败。仍要检查 response.ok，必要时使用 try/catch，并处理组件卸载后的旧响应。
