LESSON 03约 55 分钟组件 · state · effect

UI = f(state)

React 最重要的不是 JSX 语法，而是声明式关系：给定当前状态，组件返回此刻应该显示的界面。状态改变，React 再调用这个函数。

THE EQUATION

这个等式对在哪里，又错在哪里

界面 = Home(当前页, 当前周, 当前用户, 追番列表, 已看记录, ...)
像研究一个参数化函数：state 是输入，JSX 是输出。你不直接命令“把第三个 div 改成粉色”，而是改变决定颜色的状态，让函数重新计算。
渲染不变量组件渲染阶段应当像纯函数：不要在 JSX 计算过程中发请求、写数据库或修改外部对象。

这个类比的边界：真实组件还要和浏览器、网络、计时器等外部世界同步；这些动作由事件处理器和 useEffect 承担。

COMPONENTS & JSX

组件就是返回界面描述的函数

数学式
CoverArt : Anime × Variant → UI
项目代码的形状
function CoverArt({ anime, variant }) {
  const sprite = coverSpriteFor(
    anime.coverUrl,
    variant,
  );
  if (!sprite) return null;
  return <span role="img" />;
}

JSX 看起来像 HTML，但它是 JavaScript 表达式。花括号里可以放值、条件、数组映射和组件。浏览器最终看到的是 React 创建的 DOM。

{condition && <X />}

条件为真才渲染 X。先问 condition 是由哪个 state 或派生值决定的。

items.map(...)

每个数据项生成一段 JSX；稳定 key 帮 React 识别同一项。

onClick={handler}

传入函数本身，不是立刻调用它。点击发生时浏览器再调用。

<Component prop={x} />

父组件把输入传给子组件；子组件不应偷偷修改父组件 state。

EFFECTS

useEffect 是同步外部世界

effect 不是“组件里任何复杂逻辑的收纳箱”。项目中的 effect 主要处理：

  • 读取当前用户、追番和已看 API；
  • 监听浏览器 popstate；
  • 同步对话框打开与焦点；
  • 订阅系统主题或时间变化；
  • 在依赖变化或组件卸载时取消旧任务。
useEffect(() => {
  let cancelled = false;

  async function loadUser() {
    const response = await fetch("/api/auth/me");
    if (!response.ok || cancelled) return;
    setCurrentUser(await response.json());
  }

  loadUser();
  return () => { cancelled = true; };
}, []);
从依赖数组读 effect：
[]
挂载时建立一次同步，卸载时清理。
[a, b]
a 或 b 变化时重新同步。
没有数组
每次渲染后运行，通常要格外警惕。
cleanup
撤销监听、计时器或标记旧请求失效。

REQUEST LOOP

一次点击如何绕一圈回来

  1. 用户点击已看方框事件处理器根据旧 state 计算乐观的新数组。
  2. React 立即重渲染用户先看到响应，不必等网络往返。
  3. fetch() 调 API服务器认证、验证单集键并写 D1。
  4. 响应决定保留或回滚成功保留；失败恢复仍然适用的旧状态并显示错误。
乐观更新像先假设一次操作能成功，再等服务端给证明。如果反例出现，就必须回滚；而并发操作意味着不能粗暴恢复整份陈旧快照。

URL IS STATE

为什么页面状态不能只放 React 里

“播出表”“我的番剧”“统计”和“搜索”分别映射到 URL 的 ?page=。切换时使用 history.pushState，浏览器前进/后退通过 popstate 同步回 React。

导航不变量如果一个界面是用户认为的“页面”，它通常需要能被 URL 表达，否则刷新、分享和后退行为会出错。
rg -n "pushState|popstate|searchParams" app/page.tsx

READ THE BIG FILE

拆解 2111 行 Home 的阅读顺序

  1. imports：页面依赖哪些算法与数据；
  2. types：页面操纵哪些数据形状；
  3. useState：哪些量会变化；
  4. 派生值：哪些结果能由 state 计算；
  5. useEffect：和哪些外部系统同步；
  6. 事件处理器：用户动作如何改 state 或发请求；
  7. 最终 JSX：不同 activePage 渲染什么。
