JS / TS 速通：从 C++ 到 JavaScript 只差一层窗户纸

这个项目里几乎所有代码（.tsx / .ts / .js）都是 JavaScript 家族语言。你不需要从头学一门语言——只要把 C++/Python 已有的概念翻译过来，本章 40 分钟就能读完项目代码。

语言 阶段一 · 补地基 预计 40～60 分钟 前置：会 C++ / Python 基础语法即可

1为什么先学它：项目里全是 JS 家族

打开项目你会看到四种后缀，它们不是四种语言，而是同一门语言的四种口味：

后缀是什么项目里在哪
.js纯 JavaScript，最原始的口味lib/calendar.js、data/anime.js
.mjsJS 的 ES 模块版（能 import/export）scripts/*.mjs
.tsTypeScript = JavaScript + 类型标注db/schema.ts、app/api/**/route.ts
.tsxTS 再 + JSX（React 组件的写法）app/page.tsx、app/layout.tsx

类比：你学 C++ 时，.cpp 和 .h 写的都是 C++；这里 .ts/.tsx/.js 写的都是 JavaScript。TypeScript 只是给 JS 加了一层“编译期检查”，运行时执行的还是 JS。

调试输出你已经有老朋友了——console.log 就是 cout/print，功能完全一样：

随手一试 控制台打印
console.log("Hello, 番剧日历");      // 就像 cout << ... << endl;
console.log(anime.id, anime.title);  // 一次打多个，用逗号隔开
console.log({ anime });              // 直接打印整个对象，像 Python 的 print(dict)

2变量与类型：let / const / === / 模板字符串

声明变量用 let 或 const，没有 int/string 这种类型前缀——类型是运行时才知道的，这就是“动态类型”。

let 与 const 声明与赋值
let count = 0;        // 可以重新赋值
count = 1;

const season = "2025年1月";   // 不能重新赋值
season = "2025年4月";         // ❌ 报错：Assignment to constant variable

const anime = { id: "yuc-1", title: "某番" };
anime.title = "改个名";        // ✅ 可以：改的是对象内部，不是换掉 anime
类比：const 和 C++ 的 const 引用 / const 指针几乎一模一样——引用（绑定）本身不能换对象，但指向的对象如果不是 const，它的字段照样能改。一句话：const 锁的是“绑定”，不是“内容”。所以项目里到处都是 const，别慌。

比较用 ===（三个等号）。==（两个）会做隐式类型转换，是历史遗留的坑：

=== vs == 严格相等才是真相等
5 == "5"    // true  ：== 先把两边都转成数字再比
5 === "5"   // false ：类型不同，直接不等
"" == 0     // true  ：两个都转成“假值”
"" === 0    // false

// 规则：永远写 === 和 !==，忘掉 == 的存在

拼字符串用模板字符串（反引号 + ${}），不用 C++ 的 + 硬拼：

模板字符串 像 Python f-string
const name = "小夜";
const msg = `你好，${name}，今天有 ${n} 部番更新`;   // ${} 里放任意表达式

想知道一个值是什么类型，用 typeof——动态类型语言里它是你的“typeid”：typeof 5 得 "number"，typeof "hi" 得 "string"，typeof null 得 "object"（这是个历史 bug，别惊讶）。

小测：关于 const 与 C++ 的类比，下面哪句说法是对的？

const 阻止的是“把变量重新指向别的值”，不冻结对象内部。C++ 里 const T& ref = obj; 你不能让 ref 改绑另一个对象，但如果 obj 本身可变，它的成员仍能改——两者语义一致。项目里 const anime = {...}; anime.title = "..." 是合法的。

3对象与数组：struct / dict / 列表推导 全在这里

JS 的对象（{ key: value }）一口气兼任了 C++ 的 struct、Python 的 dict、C++ 的 unordered_map：

对象 键值对集合
const anime = { id: "yuc-1", title: "某番", episodes: 12 };
console.log(anime.title);        // 点号取字段（像 struct.member）
console.log(anime["episodes"]);  // 方括号也行（像 dict[key]）

const { id, title } = anime;     // 解构：一次性取出两个字段
console.log(id, title);

解构就是“把对象的字段/数组的元素一次拆进变量”，在项目里极常见。数组解构 + 展开运算符 ...：

解构与展开 拆包与合并
const arr = [1, 2, 3];
const [a, b] = arr;              // a = 1, b = 2
const [first, ...rest] = arr;    // first = 1, rest = [2, 3]

const merged = { ...defaults, ...user };  // 合并对象，后写的覆盖先写的
const copy = [...arr];                    // 浅拷贝一个数组

数组三兄弟 map/filter/reduce——map 就是 Python 列表推导，reduce 就是 STL 的 std::accumulate：

数组方法 map ≈ 列表推导
const ids = allAnime.map((a) => a.id);                    // 取出每部的 id
const ongoing = allAnime.filter((a) => a.episodes === null); // 筛出未完待定的
const total = [1, 2, 3, 4].reduce((sum, x) => sum + x, 0);   // 累加 = 10

// 项目里有一行真实代码：把每部番的 id 放进一个 Set 去重
const validAnimeIds = new Set(allAnime.map(({ id }) => id));
认亲：读到 .map(...) 心里默念“列表推导”，读到 .filter(...) 默念“筛一遍”，读到 .reduce(...) 默念“从头累加”。这三个词会占掉项目里一半的循环。

两个高频操作符：?. 与 ??

读项目时你会反复撞见 ?.（可选链）和 ??（空值合并）。它俩解决同一件事：访问一个可能为 null / undefined 的值时，别崩。

app/page.tsx 真实代码里的 ?. 与 ??
currentBeijingDateTime?.slice(0, 10) ?? null
//  ↑若 currentBeijingDateTime 是 null/undefined，整段直接得 null，不抛错
//                            ↑若左边是 null/undefined，用右边的 null 兜底
手写等价版 不用这两个操作符，得写这么啰嗦
currentBeijingDateTime !== null && currentBeijingDateTime !== undefined
  ? currentBeijingDateTime.slice(0, 10)
  : null

去重靠 Set（集合）：[...new Set(list)] 一行搞定“数组去重”，等价于把元素塞进 C++ 的 set/unordered_set 再倒出来。项目 lib/anime-selections.js 里 [...new Set(value)] 就是用它在保存前去掉重复的番剧 id。

循环写法也提一句：for (const x of list) 相当于 C++ 的 for (const auto& x : list)、Python 的 for x in list。项目 lib/calendar.js 里 for (const season of seasons) 就是在遍历每个季度。

4函数是一等公民：把函数当值传来传去

在 JS 里，函数可以赋给变量、当参数传、当返回值——你已经在 C++ 见过 函数指针/std::function，JS 只是把这套做成了默认操作，没有指针语法。

箭头函数 (参数) => 表达式
const addOne = (x) => x + 1;      // 箭头函数：把函数当值赋给变量
console.log(addOne(41));          // 42

const double = (x) => x * 2;
const result = [1, 2, 3].map(double);  // 把函数 double 直接传进去
console.log(result);                    // [2, 4, 6]

箭头函数 (x) => x + 1 等价于“输入 x 返回 x+1”，一行表达式时连 return 都能省；多行才用花括号 { return ...; }。当函数被当成参数传给 map/forEach 时，它叫回调函数——意思是“这个函数你先拿着，稍后我来调用”。

lib/calendar.js 真实代码：用回调生成一周 7 天
const days = Array.from({ length: 7 }, (_, offset) => addDays(weekStart, offset));
//                  ↑造 7 个空位      ↑回调：对第 offset 个空位，算出 offset 天后的日期
类比：C++ 里 std::transform(v.begin(), v.end(), out, f) 把 f 传进去逐元素变换；JS 的 v.map(f) 是同一件事，只是 f 常用 (x) => ... 现写现传，不必单独声明。

顺带分清 forEach 和 map：forEach 只“跑一遍做副作用”（打印、发请求），不返回新数组；map 会“返回一个新数组”。想留结果用 map，只想遍历一遍用 forEach。

5模块、空值、truthy、错误处理

模块：import / export

import/export ≈ Python 的 import 或 C++ 的 #include，但有一点关键不同：只有显式 export 的东西，别的文件才能 import，没导出的就是私有。

lib/calendar.js 导出与引入
// calendar.js 里：导出一个具名函数
export function addDays(isoDate, days) { /* ... */ }

// 另一个文件里：按名字引入
import { addDays } from "./calendar.js";

// default export：每个模块最多一个“默认导出”，import 时可以随便起名
export default function main() { /* ... */ }
import main from "./main.js";

null vs undefined，以及 truthy/falsy

JS 有两个“空”：undefined 表示“还没赋值 / 不存在”，null 表示“明确地没有值”。你声明变量不赋值，它是 undefined；函数“没找到结果”时，主动返回 null。

判断真假时记住一串假值（falsy）：0、""、null、undefined、NaN，其余全是真。和 Python 很像（空串、空容器是假），但有两个坑：字符串 "0" 是真、空数组 [] 是真。

truthy / falsy 真假速查
if (0) {}         // 假
if ("") {}        // 假
if (null) {}      // 假
if (undefined) {} // 假
if (NaN) {}       // 假
if ("0") {}       // 真！字符串 "0" 不是数字 0
if ([]) {}        // 真！空数组也是真
小练习：判断下面表达式的值（点击看答案）

"" || "默认" → "默认"（|| 从左找第一个真值）；0 || "a" → "a"；1 && 2 → 2（&& 全为真时取最后一个）。这两个运算符常用来给变量设默认值，和第 6 节的 ?? 一起看。

错误处理：throw / try / catch

抛错用 throw，捕获用 try/catch，和 C++ 几乎一样。内置错误类型里你会在项目里高频看到 RangeError（值超出合法范围）和 TypeError（类型用错了）。

lib/calendar.js 真实代码：日期非法就抛 RangeError
if (!match) throw new RangeError(`Invalid ISO date: ${isoDate}`);

try {
  parseIsoDate("2025-13-40");              // 会抛错
} catch (error) {
  console.log(error instanceof RangeError); // true
  console.log(error.message);               // "Invalid ISO date: ..."
}

小测（多选）：下面哪些值在 if (x) {...} 里会被当成“假”，从而跳过花括号？

假值（falsy）只有五个：0、""、null、undefined、NaN。注意 "0" 是字符串，非空字符串一律为真——这是和“把 0 当假”最常混淆的地方。

6TypeScript：给 JS 装一套“编译期检查”

TypeScript 做的事只有一件：给变量、参数、返回值标注类型，在运行前抓错。运行时它不存在——最终执行的都是编译后的普通 JS。

类型标注 三种写法
interface Anime {                 // interface：描述对象的形状
  id: string;
  title: string;
  episodes: number | null;        // 联合类型：要么 number，要么 null
}

const anime: Anime = { id: "yuc-1", title: "某番", episodes: null };

type AnimeId = string;            // type 别名：给类型起个短名字
type MaybeNumber = number | null; // 联合类型也能起别名

两个“未知类型”要分清：any 是“放弃检查、随便用”（等于退回纯 JS，尽量别用）；unknown 是“类型确实未知，但用之前必须先判断它是什么”，更安全。项目里写的是 unknown。

app/api/anime-selections/route.ts 真实代码里的 unknown
const payload = (await request.json()) as { animeIds?: unknown };
//              ↑服务器收到的 JSON 里到底是什么类型，事先不知道，标注成 unknown

检查命令是 tsc --noEmit——只报错、不生成任何文件，项目里封装成 npm run typecheck。这就像 C++ 的编译期报错：还没运行，就能把“把 null 当 number 用”这类错误拦在门口。

终端 只检查不输出
npm run typecheck     # 等价于 tsc --noEmit：全项目静态检查，报错但不产出文件
项目里怎么用：npm run typecheck 是 npm test 的第一步（后面还有构建和跑测试）。所以“类型没过”这道门会直接拦住你的提交——就像 C++ 编译不通过一样。

小测：TypeScript 的类型检查（tsc --noEmit）发生在什么时刻？

类型检查是静态的：tsc 读源码、检查类型是否自洽，这一步发生在构建/提交前，浏览器里跑的已经是不带类型标注的 JS。和 C++ 一样，类型错误在“运行前”就被抓住——这正是 TypeScript 存在的意义。

7异步：为什么代码里有满屏的 await

先懂“为什么”：网页是单线程的，而网络请求（比如请求服务器读你的追番列表）不知道要等多久。如果像 C++ 那样同步阻塞地等，整个页面就会冻住。所以 JS 用异步：发起请求后先不干等，等结果回来再继续。

Promise 版 一个“未来值”的盒子
fetch("/api/anime-selections")         // 发请求，立刻返回一个 Promise（承诺）
  .then((res) => res.json())           // 等响应回来，再解析成对象
  .then((data) => console.log(data))   // 再打印
  .catch((err) => console.error(err)); // 哪一步出错，走这里

Promise 就是“未来某刻才会有的值”的盒子：现在拿不到，但可以通过 .then 登记“值到了以后做什么”。而 async/await 只是它的语法糖——写起来像同步代码，可读性高得多：

app/api/anime-selections/route.ts 真实代码：await 版
export async function GET() {
  const user = await getSessionUser();   // await：暂停，等这个值“回来”再往下走
  if (!user) {
    return Response.json({ error: "Sign in required" }, { status: 401 });
  }
  const db = await getDb();              // 等数据库连接就绪
  // ... 拿到 db 再查数据
}
类比：await 相当于 C++ std::future<T> 的 .get()，或 Python 协程里的 await——“暂停当前函数，等这个值就绪”。区别是 JS 里只有 async 函数里才能用 await。
必背结论：一个 async 函数永远返回 Promise，即使你写 return 42;，调用者拿到的也是“装着 42 的 Promise”。所以调用 async 函数时，要么 await 它，要么 .then 它，不能直接当普通返回值用。

定心丸：斐波那契，三语言并排

同一个递归，看看你离读懂 JS 到底有多近——唯一的“新东西”只是 const 和 =>：

fib.cpp C++
int fib(int n) {
  return n <= 1 ? n : fib(n - 1) + fib(n - 2);
}
fib.py Python
def fib(n):
    return n if n <= 1 else fib(n - 1) + fib(n - 2)
fib.js JavaScript
const fib = (n) => (n <= 1 ? n : fib(n - 1) + fib(n - 2));

看到了吗？语法障碍比想象中小得多。剩下要做的，就是打开项目，边读边查——下一章我们搞懂“网页是怎么跑起来的”。

练手：打开 app/api/anime-selections/route.ts，数一数里面出现了几个 await、几个 Response.json(...)，再找到 status: 401 对应哪段逻辑。能通读下来，说明本章语法你已经拿下。
