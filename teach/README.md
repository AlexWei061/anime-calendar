# 读懂你的番剧日历

这是给数学系、掌握 C++ / Python 基础并有信息学竞赛经验的学习者制作的项目教材。以当前工作区的真实源码为依据，从数据结构和算法过渡到浏览器、React、API 与数据库。

## 打开

直接用浏览器打开本目录的 **index.html**。正文、源码快照和互动实验均可离线运行，无需安装依赖；官方延伸阅读链接需要联网。

也可从项目根目录启动本机预览：

```bash
python3 -m http.server 8766 --bind 127.0.0.1 --directory teach
```

然后访问 [项目学习室](http://127.0.0.1:8766/)。退出该终端服务后，这个预览地址停止工作；本地 index.html 仍可直接打开。

桌面侧边栏提供“打印整本教材 / 存为 PDF”。浏览器的打印对话框里选择“存储为 PDF”。“专注阅读”可以收起侧栏，正文底部仍可切换前后课程。

## 建议的七次学习安排

| 次数 | 内容 | 完成标志 |
| --- | --- | --- |
| 1 | 第 1 课：语法 | 解释十行搜索函数，找到调用者。 |
| 2 | 第 2 课：网站执行环境 | 在 Network 区分页面、脚本、API 请求。 |
| 3 | 第 3 课：React | 画出输入、状态、派生结果与界面的依赖图。 |
| 4 | 第 4 课：排期 | 推导凌晨边界、先行多集与区间分栏。 |
| 5 | 第 5、6 课：保存与数据 | 解释完整收藏 PUT、单集身份与数据来源。 |
| 6 | 第 7 课 + Bug 实验室 | 独立修好三个练习副本，6 个断言通过。 |
| 7 | 第 8 课：维护 | 完成闭卷验收，写一份有验证方案的维护提案。 |

每课按“模型 → 真实代码 → 预测/操作 → 小测 → 实际验收”进行。第一遍阅读约 6 小时，动手再留 3–5 小时，可分多天完成。不需要一次读完 app/page.tsx。

## 三个可编辑练习

只修改 `teach/exercises/repair.mjs`：

```bash
node --test teach/exercises/repair.test.mjs
```

初始 **3 通过、3 失败** 是刻意设计：05:00 边界、全角搜索、逐集身份键分别有一个故障。修复后同一命令应 **6/6 通过**。

网页里的“故障版本 / 尝试最小修复”按钮会实际执行教学函数和断言，但不会编辑这个文件，也不会写入真实项目或账号数据。

核对参考实现：

```bash
TEACH_SOLUTION=1 node --test teach/exercises/repair.test.mjs
```

参考答案位于 `exercises/solution.mjs`。这个命令通过只说明参考答案正确，不代表你已修好 `repair.mjs`。

在内存 SQLite 中读取真实迁移：

```bash
python3 teach/exercises/schema.py
```

该练习只读 `drizzle/*.sql`，在内存中建立四张表，结束即释放；不连接 D1，不修改 `.wrangler`。

## 目录

| 文件 | 用途 |
| --- | --- |
| index.html、styles.css、app.js | 独立阅读网站、导航、进度、源码弹窗与打印。 |
| course.js | 八课正文、小测、实验说明、维护速查卡。 |
| labs.js | 搜索、状态队列、凌晨映射、区间分栏、请求流程与故障模拟。 |
| snapshot.js | 28 个重点文件的源码快照、行号依据与 SHA-256。 |
| snapshot.py | 只读取明确白名单中的项目代码，更新快照。 |
| exercises/ | 可编辑故障副本、参考答案、断言和内存数据库练习。 |
| tests/site.test.mjs | 教材的内容引用、模型正确性和导航事件检查。 |

学习进度用浏览器 localStorage 的 `ac-teach-progress-v2` 保存，与真实项目的 `ac-theme`、追番账号数据独立。不同浏览器、file 地址与 HTTP 地址可能各自保存进度；存储不可用时仍可学习，但不会跨刷新保留进度。
